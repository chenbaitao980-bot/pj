## 相对 0.2.9-rc.1 的改动

### 1. 每个工作区的自定义注入提示词

- 面板 `http://127.0.0.1:8799/` 的每个工作区卡片新增「本工作区自定义注入提示词」文本框：
  - 保存写入 `<工作区>/.dsh/prompt.md`（纯文本 / Markdown，上限 20,000 字符；清空即删除文件）；
  - 内容由 `dsh-plugin-scope` 的 Host 侧注册为 system prompt 段 `plugin-scope:workspace-prompt`（order 9100），按**会话的项目根**（`session.header.cwd`）读取，因此同一台机器上不同工作区的会话拿到各自的提示词；
  - 会话中途用工具切换 working directory 不会收窄作用域——工作区提示始终属于项目根；
  - 文件按 mtime 缓存，每个模型请求读取不额外落盘。
- 新增命令：
  - `/pluginscope prompt` 查看当前工作区提示词与文件路径；
  - `/pluginscope prompt-set <文本>` 单行写入；
  - `/pluginscope prompt-clear` 清空。
- 面板与插件写同一份文件，面板保存后「下一个模型请求起生效」。

### 2. `/pluginscope` 接受任意插件名

- 0.2.9 安装包里的命令仍是 trellis / gitnexus / codegraph 白名单；本版放宽为任意插件名（`/pluginscope @local/dsh-side-chat off` 等），与面板「所有全局插件都按工作区记录」的规则一致。
