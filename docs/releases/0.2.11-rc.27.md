## 2. ③ 折叠语义修正

rc.26 保留了「有活跃任务时强制展开」，实机上表现为：会话跑着点折叠没反应，任务结束后又突然收起。本版按用户要求改成纯用户控制。

`plugins/dsh-task-board/client.js`：

```js
// 旧：const collapsed = userCollapsed && !anyActive;
const collapsed = userCollapsed;

const toggleCollapsed = function () {
  const next = !userCollapsed;
  setUserCollapsed(next);
  writeCollapsedFlag(sessionId, next);
};
```

- 删掉 `anyActive` 渲染期覆盖与对应计算；
- 折叠状态仍写 `dsh-task-board:collapsed:v1`（`{[sessionId]: true}`），切会话、热重载、重启都在；
- 折叠后 header 的「N 进行中」与状态点继续更新，只是不再展开列表。

## 3. 热部署

新增 `scripts/dev-hot.mjs`：

```
node scripts/dev-hot.mjs                       # 全部插件同步一次
node scripts/dev-hot.mjs --watch               # 改完即同步（推荐）
node scripts/dev-hot.mjs --only dsh-task-board
node scripts/dev-hot.mjs --reconcile           # 额外 bump cordis.patch.yml
```

链路：

1. `node --check` 校验插件入口，坏代码不落到 live profile；
2. 调 `frozen-build-src/sync-live-plugins.js`，镜像到 `~/.dsh/plugins/<dir>` 与 `~/.dsh/profiles/desktop/node_modules/<pkg>`，并补 `dependencies` / `dsh.profile.bundles`；
3. 只有**新插件**或 manifest 变化才往 `cordis.patch.yml` 追加 `# dev-hot <ts> <name>` 触发宿主 reconcile；
4. 已注册插件的**内容改动**由 `@deepseek-ai/dsh-client-hmr` 处理：它每 500ms 轮询入口产物的 mtime/ctime/size，变了就把新 bundle 换进已打开的页面（插件内 React 状态会丢，会话/工作区状态保留）。

所以改 `client.js` 的循环变成：存盘 → 0.5-1 秒后界面自己换。**不重装、不刷新、不重启**。

局限：`dsh-client-ui-chat` / `workspace` 这类**已编译 bundle** 的 patch 不走这条路，仍需重打包安装。
