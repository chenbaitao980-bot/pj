## 2. dsh-session-tracker：去标记、加「副会话」、不进待确认

Tracker 直接读 `row.title`，而副会话标题是
`⧉ <mainSessionId> · 副会话 N`。rc.22 会让它在追踪面板里显示整段 UUID，
并作为顶层 Session 进入「已完成待确认」。

- 新增 `SIDE_TITLE_RE = /^⧉ [^ ]+ · /u` 与 `sideTitleText()`；
  `entry.title` 只保留人类名。
- `entry.side` 标记副会话；行标题加 `↳` 前缀，行 meta 加「副会话 / Side chat」
  标签（pending / running / done 三处统一走 `withScope()`）。
- `completionUnread` 的副会话不再进入 `done` 桶：它已经在左栏树里，
  不需要再以「已完成待确认」重复出现；等待回答/审批的副会话仍会进入
  `pending`，不会漏提醒。
- 桌面通知标题也走 `sideTitleText()`，空标题回退「未命名会话」。

## 4. 嵌套副会话：同步游标按父会话过滤

在副会话里再按 `Ctrl+;` 会 fork 出嵌套副会话。它继承的日志里带着指向
**原始主会话**的 `side-chat-memory` 消息；旧 `lastSyncedSeq(session)` 会拿这些
消息的 `source.parentTo` 当游标，导致嵌套副会话跳过自己父会话的新事件。

- `lastSyncedSeq(session, parentId)` 只接受 `source.parentId === parentId`
  的记忆消息；继承前缀里指向别的父会话的快照不再移动游标。
- 调用点改为 `lastSyncedSeq(session, parentId)`。
- Host 逻辑测试仍为 `host side-chat tests: OK`（`parentTo = 5`、第二次 step
  不重复、replace 不复活、记忆插在尾部 user prompt 之前）。
