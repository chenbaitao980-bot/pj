## 0. 排查结论（守护是否存在）

守护在 rc.9 已存在并在跑（`~/.dsh/todo-nudge.log` 有逐条记录），但它只会「写占位 → 小模型规划一次 → 回合结束收口 in_progress」，对照用户截图那一轮的会话日志定位到三个根因：

1. **规划超时后面板永远停在提示词**：第 32 回合模型没写清单，守护写了「本轮：这个翻译我懂是模型搞的…」，规划小模型 8 秒超时返回空，之后 30 多次工具调用期间再没有任何更新——守护没有跟随实际进度的机制。
2. **规划结果被误判为模型清单，守护当场退出**：宿主 `session.append` 会对事件数据做 JSON 快照，守护用对象引用判断「是不是我写的」永远不成立，于是规划清单被当成模型清单，`auto=false`，守护对这一轮撒手。
3. **回合结束残留待处理**：第 31 回合规划写了「后续按该模型推进字幕任务（pending）」，回合结束的审计只把 in_progress 收口，pending 原样留下。

## 1. 任务守护（@local/dsh-todo-nudge 1.1.0，宿主侧）

- **归属判定改为写入标记**：守护写入的 `todo/write` 带 `by: 'task-guardian'`，不再依赖对象引用。
- **规划**：请求落盘 1.2 秒后若模型仍未写清单，小模型（同供应商 flash/mini 类、最低推理档）按请求规划 1~5 条；超时 15 秒，失败回退主模型；仍失败则之后**每一步都重试**（≥6 秒间隔），不会再卡在占位上。
- **实时审计与调度**：回合运行中每 ≥4 次工具调用且 ≥15 秒，守护把「请求 + 追加要求 + 当前清单 + 最近 16 条实际动作（工具调用与对用户说的话）」交给小模型，更新状态（完成/进行中/待处理），按真实进展补任务、删不再需要的 pending、拆过于笼统的项；已完成的条目不会被改回。
- **模型自己写的清单**：守护不覆盖、不增删；只有模型连续 6 次工具调用没更新清单时才做一次「只改状态」的校正。
- **运行中追加消息**：不再把清单换成「本轮：<追加内容>」，而是立即触发一次审计，把追加要求并入清单。
- **回合结束审计**：正常结束时，对每条未完成项判定 `done`（标完成）/ `drop`（预想的后续工作，移除）/ `open`（确实没做完），并判断最终回复是否在等用户确认；结论写入清单。被中止/出错的回合保持原状（面板显示「已暂停」）。审计模型无响应时按规则收口：进行中的收为完成，守护预想的 pending 移除，模型自己计划的 pending 保留为未完成。
- **约束（追问一次）**：主会话里确实有未完成项、且不是在等用户回复时，守护排队一条可见消息「【任务守护】本轮任务清单还有 N 项未完成：…请继续完成…」开启一个续跑回合，续跑回合沿用原清单。每个用户请求最多追问 1 次；子智能体不追问（结果已交还父会话），只收口清单。可用环境变量 `DSH_TASK_GUARDIAN_CONTINUE=0` 关闭。
- **新投影 `taskGuardian`**：由会话事件推导（不额外写事件），向面板提供当前动作、校正次数、回合结束原因与审计结论。
- 规划/审计都是直接 `llm` 调用：不建会话、不进左侧列表、不进主 agent 上下文；典型一轮（30 次工具调用）约 1 次规划 + 4~6 次审计 + 1 次终审，均为小模型、每次几百输出 token。
- 系统提示规则补一句：任务守护会对照实际动作审计清单，回合结束时未完成的条目会被追问。
- 每个会话（主会话与每个子智能体）独立维护守护状态；空闲 2 小时的状态自动回收；日志超过 512 KB 自动截断。

## 2. 任务面板（@local/dsh-task-board 1.1.0，客户端）

- **实时动作**：进行中的任务下面显示「正在：运行命令 · 找 sherpa / recognizer 相关类」「正在：读取 · D2.java」等（取自工具调用的 description / 文件名 / 命令首行）；还没有清单时，「运行中 · 等待任务清单…」也替换为当前动作。
- **守护状态行**：运行中显示「任务守护 · 跟踪中 / 已按实际进度校正 N 次」；回合刚结束显示「任务守护 · 正在审计本轮…」；审计后显示「本轮审计：完成 X 项 · Y 项未完成 · 移除 Z 条预想任务 · 等你确认 / 已要求继续」，悬停看原因。
- **空闲时不再显示「待处理」**：回合结束后的未完成项按审计结论标「待继续」（已追问）/「待确认」（在等你回复）/「未完成」；回合刚结束、结论未到的 30 秒内标「审计中…」，超时自动回落。
- 显式空清单会同时清掉面板的「粘住」缓存，下一回合不再闪回旧清单。
