## 1. 新增：billion-context 0.1.213（ranxianglei/billion-context）

- **内置方式**：npm 发布包放进 profile `node_modules`（`billion-context` + `mysql2` 及其依赖；
  `zod 4.6.7` 包内已有），profile `package.json` 的 `dependencies` 与 `dsh.profile.bundles`
  登记，默认启用、离线可用。随宿主下发的配置在 `%USERPROFILE%\.config\billion-context\billion-context.json`。
- **行为**：宿主内原生插件 + 本地压缩代理（只监听 `127.0.0.1` 随机端口，watchdog 绑定宿主进程）；
  向会话注入 `compress` / `decompress` / `search_context` / `acp_status` 工具、`/acp` 命令与
  顶栏「上下文」标签页。压缩是**模型自决式**：可折叠内容每增长 50K token（`compress.nudgeGrowthTokens`）
  提醒一次，逼近模型窗口时由 preflight 硬兜底（95% 紧急档）；折叠可逆、可搜索、对前缀缓存友好。
- **重要副作用**：它会关闭 DSH 自带的自动压缩（bundle 补丁把 `compaction-basic` 设为 `auto: false`，
  并给 Web presets 加 gate）。卸载必须从 profile `dsh.profile.bundles` 移除 `billion-context`，
  不能只停插件（否则 preset 会等一个不存在的 gate）。
- **安装方式说明**：安装页给的 `github:...#commit` 方式会被插件自身的 prepare 门禁拒绝
  （仓库不带 `dist/`，门禁明确要求装 npm 发布包）；npm 上有同版本 0.1.213。
- **pnpm 11 修复**：profile `pnpm-workspace.yaml` 的 `allowBuilds` 对 `file:` 依赖必须写精确
  depPath 键（`dsh-purge@file:../../plugins/dsh-purge`），只写包名在 pnpm 11 默认
  `strictDepBuilds=true` 下不匹配，会让任何 `dsh plugin add` 失败。payload 与本机已同步修正。
- **verify-install 新增 4 项卡门**：插件注册、插件文件（`dist\agent\dsh-native.js` /
  `dist\index.js` / `dsh.bundle.patch.yml`）、bundle patch 含 `bili-native` + `bili-compaction-gate`、
  `compaction-basic auto: false`。缺任何一项打包中止（当前 72 项全过）。
