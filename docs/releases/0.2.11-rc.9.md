本版按两条用户反馈落地：**Ctrl+; 变成真正的副会话**，以及**任务清单在新回合/插入调整时不再掉线**。两个插件都先热部署到正在运行的工作台，再升版打包。

## 1. 副会话（@local/dsh-side-chat）

- **`Ctrl+;` 带历史分叉**：主会话有已完成回合时，副会话分叉主会话历史后打开在右侧面板——它能读到任务 A 的上下文，可以回答「做到哪里了」、汇报进度，并继续协同执行；空白主会话（无已完成回合）才在同一工作区新开一个空会话（与插件元数据一直宣称的行为对齐，此前实现是每次新开空会话）。
- **关闭不丢内容**：主会话与副会话的关联持久化到 `localStorage`（`dsh-side-chat:links:v1`）。关掉标签后再按 `Ctrl+;`，按创建顺序重新打开最早一个未打开的副会话，内容原样恢复；关掉整个应用也一样（右侧面板布局本身按会话持久化）。
- **可开任意多个**：所有记住的副会话都已打开时，再按 `Ctrl+;` 就新建下一个；右侧面板「+」在有副会话时继续新建副会话（原 `claimAddTab` 逻辑保留）。
- **健壮性**：宿主拒绝空会话分叉（`session/fork-unavailable`）时回退为同工作区新会话；会话列表处于 pending 时不做失效清理，避免误删关联；会话被删除后下一次按键自动剔除对应关联。
- **右侧专属，不再挤占左侧列表**：副会话是真实会话，原本会在左侧工作区列表里多出一行。新增冻结补丁 `tools/patch-side-chat-hide.js` 让 `sessionVisible` 读取插件的 `isSideSession` 判定，副会话只存在于右侧面板；`Ctrl+;` 仍按关联恢复，标签与保留机制不变（插件不在时判定为可选，行为与上游一致）。
- 副会话是独立 Session，有自己的 agent loop 与任务清单，可与主会话在同一工作区并行工作。

## 2. 任务清单实时性（@local/dsh-task-board）

- **不再因新回合而闪空**：宿主在每个 `turn/start` 把 `todos` 投影重置为 `null`，等 agent 重新 `todo_write` 才恢复。主会话临时插入任务、副会话开始自己的回合时，面板原本会整块消失。现在按 agent 记住最近一份非空清单，`null` 期间继续展示；新的 `todo_write` 一到立即替换；显式空数组仍然清空。
- **子 agent 清单同样粘住**：子 agent 开新回合时不再从面板上消失，多 agent 下拉切换不受影响。
- **会话运行期间面板始终显示**：即使还没有任何任务，运行中的会话也会显示「运行中 · 等待任务清单…」，不再因 0 条任务而整块消失；空闲且无任务时才隐藏。

## 3. 任务清单：规则 + 兜底 + 逐条备注（@local/dsh-todo-nudge / @local/dsh-task-board）

- 规则收紧为：**只要这一轮会调用工具（哪怕只有一个步骤），就必须先用 `todo_write` 建立清单**，并每完成一个动作立即更新（完成改 completed、新增补上、下一步设 in_progress），不要等全部做完才写；只有纯问答不建清单。
- **宿主侧兜底 + 审计**：每个回合开始时，如果模型没有写清单，宿主自动写入一条「本轮：<你的请求>」（进行中）；回合**正常完成**时审计并把遗留的「进行中」收口为已完成（`pending` 保持不动），被拦截/中止则保持进行中。模型一旦自己 `todo_write`，兜底立即让位。宿主禁止在事件发布期间重入 append，所以守护写入走定时排队 + 退避重试，并在写入前复核当前清单，绝不覆盖模型已写的列表。兜底按会话独立维护，**每个子智能体互不覆盖**；不向模型发送任何消息。每回合都会重写「本轮：…」（上一轮已结束也一样）；标题以本轮实际请求为准——`turn/start` 先占位，本轮用户消息一落盘就刷新，避免显示上一条消息。
- **独立小型规划 agent**：回合开始约 1.5 秒后若模型仍未写清单，宿主用一个小模型（优先同供应商 flash/mini/haiku 类，失败回退主模型）把本轮请求拆成 1–5 条真实任务（首条 in_progress、其余 pending），替换占位项；模型自己 `todo_write` 后规划立即作废/中止。规划是**直接 `llm` 调用**：不创建会话、不进左侧列表、不进入主 agent 上下文，只多花几百输出 token。
- **逐条任务备注**：任务面板每条任务右侧有 ✎ 备注按钮；回车或「推送」会把 `任务「…」的备注：…` 作为消息实时推送给该任务所属的智能体——运行中按 `steer` 在下一步送达，空闲时按 `queue` 开启新回合。备注按「会话 + 任务内容」持久化在本地，重启不丢；多子智能体各自独立。
- 规则与兜底属于宿主侧代码，随下次宿主启动生效；备注 UI 是客户端插件，已热更新。

## 4. 按工作区面板保活（dsh-plugin-scope）

- 现象：插件页「在浏览器打开」指向固定地址 `127.0.0.1:8799`，面板辅助进程不在时浏览器报 `ERR_CONNECTION_REFUSED`；宿主只在 boot 时尝试拉起一次，进程退出后无人再管。
- 修复：宿主侧 `apply` 增加 30 秒看护（`ensurePanel` 先 600ms 探测端口，掉线才重新 spawn，detached、无窗口），宿主存活期间面板不会再无声掉线。本次已在当前工作台手动拉起面板（`/`、`/usage?range=30d`、`/api/state` 均返回 200）。
