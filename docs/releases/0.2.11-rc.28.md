## 1. 本版目标

切会话「秒开」：把等待从「点开之后」挪到「空闲时间」。

## 2. 为什么之前还是看到「载入历史…」

`Session.open()` 会同步把 `openState` 置成 `loading`，等第一帧 snapshot 到达才变 `open`；这期间消息区没有记录，只能显示提示。rc.26 把提示换成了骨架，但只要没预取，切换仍然是「先空一下」。而 hover 预取只覆盖鼠标划过的行——键盘切换、刚打开的列表、点击快过 150ms，都命中不了。

## 3. 本版做法

`plugins/dsh-cc-touch/client.js` 增加空闲批量预取：

- 启动 1.2s 后取最近会话列表（`ctx.sessions.list.getSnapshot().byId`），按 `updatedAt` 降序取前 **8** 个；
- 串行 `open()`，每个间隔 **120ms**，只对 `openState === 'cold'` 的会话生效（`open()` 本身幂等）；
- 会话列表变化时最多每 **30s** 重新扫一次（600ms 防抖）；
- 插件 dispose 时清掉所有 timer 与 list 订阅。

配合已有的 hover 通道（`onPointerEnter` 后 150ms），常见路径变成：

| 场景 | 之前 | 现在 |
| ---- | ---- | ---- |
| 鼠标划过再点 | loading 一段 | 0（hover 已 warm） |
| 键盘切到最近会话 | loading 一段 | 0（空闲已 warm） |
| 切到第 9 个以后的会话 | loading 一段 | 仍有 loading，但用骨架而非文字（rc.26） |

预取的内存上界：每个 Session 只保留 `HISTORY_PAGE_OPTIONS` 的 500 条消息，8 个会话封顶。
