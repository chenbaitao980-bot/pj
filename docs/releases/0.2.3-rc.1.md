## 相对 0.2.2-rc.1 的改动

### 新增能力（冻结版补丁）

1. **不用工作区新建会话**
   - `dsh-client-ui-conversation`：无 workspace 时 chip 标题回退到 cwd 标签，使 `inert` 闸门放行。
   - `dsh-client-ui-workspace`：工作区选择器新增「不使用工作区」项，走 `sessions.create({})`（Host 用 `defaultCwd`）并打开会话。
   - 补丁脚本：`frozen-build-src/patch-no-workspace.js`（8 处编辑，唯一命中校验，可重入）。

2. **副会话快捷键 `Ctrl+;`**
   - 官方 `session.fork` 通道复用：fork 出的是真会话，主会话在后台继续跑。
   - `sideOrigin` 记住起始会话，连按可开出多个副会话而不产生「fork 的 fork」。
   - 补丁脚本：`frozen-build-src/patch-side-session.js`。

### 插件

3. **`@local/dsh-toolcall-tone`**（工具调用配色）
   - MCP 工具（`mcp__*`）紫罗兰左边条，插件工具（`artex_`/`purge_` 等）琥珀左边条，普通命令不变。
   - 已随 payload 出货：`dsh-home/plugins/dsh-toolcall-tone` + profile `node_modules` + 清单注册。

### 未包含

- 多工作区（会话模型仍是单 `workspaceId` + 单 `cwd`）。
- `/` 菜单在目标运行时的异常：沙箱实测三种状态下均正常（25 / 30 / 30 条候选），尚未复现，等现场样本。
