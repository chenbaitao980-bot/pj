## 相对 0.2.11-rc.37 的改动

### 1. 新增 dsh-oil-ui 0.4.13（Oil UI 的 DSH 原生插件）

- 来源：`github:oil-oil/dsh-oil-ui#cb14eef6723fdd518acb581c922aaaaea13105ac`（v0.4.13，README 指定的 Release commit）。
- 注册 5 个原生工具：`oil_ui_skill_status` / `oil_ui_explorer` / `oil_ui_shoot` / `oil_ui_media` / `oil_ui_image`。
- 内置公开 `oil-ui` Skill（Lite 0.33.4，44 个文件），随包发布；`oil-ui-pro` 存在时按原文优先。
- 注册 3 个 Slash 命令：`/oil-ui-status`、`/oil-ui-explore`、`/oil-ui-review`。
- 工作流：查 Skill 状态 → 3 方向探索并打包 `style-explorer.html` 同屏对比 → 选定方向实现页面 → 真实无头浏览器截图 / 交互 / 多端巡检 → 看真图迭代。

### 2. profile 依赖补齐（离线可跑）

插件运行时依赖 `acorn`、`parse5`（自带 entities 9）、`postcss`、`postcss-value-parser`、`nanoid`、`picocolors`、`source-map-js`，已复制进 `dsh-home/profiles/desktop/node_modules`，装机后不联网也能加载。
`@deepseek-ai/dsh-llm`、`@deepseek-ai/dsh-tools` 属宿主 peer，按既有插件同样方式由 `resources/app/dsh/node_modules` 提供。

### 3. 装箱

- `dsh-home/plugins/dsh-oil-ui` 与 `dsh-home/profiles/desktop/node_modules/dsh-oil-ui` 双份镜像。
- `profiles/desktop/package.json` 增加依赖 `dsh-oil-ui = file:../../plugins/dsh-oil-ui` 与 bundles 条目。
- `FROZEN-BUILD.json` 增加 `dshOilUi` 组件说明；版本戳三处（app / dsh runtime / manifest）统一为 0.2.11-rc.38。

## 已知限制

- `oil_ui_shoot` 需要本机 Chrome / Chromium；录屏抽帧（`record` / `motion`）另需 `ffmpeg`。
- `oil_ui_image` 优先用本机 `image-gen`（需 python3）；否则读 `OIL_TOKEN` 或 `~/.config/oil/config.json` 走 oiloil 在线生图。
- 本机未安装 `oil-ui-pro`，当前跑内置 Lite；Pro 的截图精修、多状态连拍、素材/生图完整分册不可用。
- 插件工具在会话启动时注册，安装后需新开会话才会出现在工具列表里（当前会话只即时拿到了 `oil-ui` Skill）。
