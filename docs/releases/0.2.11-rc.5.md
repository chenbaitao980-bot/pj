## 相对 0.2.11-rc.4 的改动

### 1. `/purge revert` 不再清掉冻结补丁

- 根因：dsh-purge 的 `.dshpurge.bak` 是官方原件，revert/uninstall 会整文件还原；冻结版打在同一文件里的界面补丁（待办面板、工作区 chip、不使用工作区）会一起消失。
- 修复：`dsh-purge` 新增 `reapplyFrozenPatches()`——revert / `purge_revert` 工具 / 面板 HTTP revert / 卸载，四条路径在还原后都会调用它。
  - 从 `aiBase` 推出安装根，用随包的 `tools/patch-todo-panel.js`、`tools/patch-slash-plugin-group.js`、`tools/patch-task-board.js` 重打；
  - 优先使用安装包自带的 node（Electron 宿主里 `process.execPath` 是 exe，不能直接跑脚本）；
  - 脚本不存在（非冻结版）时安静跳过；重打失败只告警，不阻断 revert。
- 打包侧：`Build-FrozenSetup.ps1` 现在会把 repo 的 `dsh-purge/` 与三个补丁脚本一起同步进 payload。
- 实测：在隔离树里把 bundle 还原成官方原件后调用 `reapplyFrozenPatches()`，两个 bundle 重新带上 `dsh:todo-live-v2` 与 `"plugin": "Plugins"`，`node --check` 均通过。

### 2. 任务面板改由 `@local/dsh-task-board` 接管

- 上游的 `conversation-todo-dock` 注册由 `patch-task-board.js` 关闭（避免两块面板叠加），新插件在同一个 dock 上渲染。
- **子 agent 面板**：主会话一块，每个直接子 agent 各一块；子 agent 数量 > 1 时出现可横向滚动的切换条，每块显示自己的任务和 `已完成/总数` 徽标，点击切换查看。
- **暂停不转圈**：读取会话 `running` 状态；会话停止/中断时，`in_progress` 条目显示为「已暂停」+ 静态空心点，不再出现永不停止的转圈动画。
- 面板默认展开；任一面板出现进行中条目时自动展开；点表头收起。
- 数据源：主会话用实时 `todos` 投影，子 agent 用会话列表里各自的 `projectionValues.todos`。

### 3. 构建与自检

- `verify-install.ps1` 新增：`dsh:todo-board-replaced` 标记、`@local/dsh-task-board` 注册与文件检查。
- FROZEN-BUILD.json 的 components 增补 `todoBoard` / `todoNudge` / `purgeRevert`。
