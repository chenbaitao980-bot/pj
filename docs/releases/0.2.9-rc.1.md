## 相对 0.2.8-rc.1 的改动

### 1. 工作区多选真正挂上附加目录

- 0.2.8 的多选只建了主工作区：`ctx.get("remote").commands` 被访问器拒绝（`cannot get property "remote.commands" without inject`）。0.2.9 改为 `ctx.inject(["remote", "remote.commands"], …)`，命令实际执行。
- 实机验证：多选 FireShot + pj 后，会话 roots 执行结果为 `{"ok":true,"value":{"result":{"kind":"success","text":"已关联：E:\\claude\\project4\\pj…"}}}`。

### 2. roots 改成会话投影（客户端可见、重启不丢）

- `@local/dsh-multi-workspace` 注册 `multiWorkspaceRoots` 会话投影，折叠会话日志里的 `command/run` / `command/done`（`/roots …`）。
- 不再写 `~/.dsh/multi-workspace/roots.json`；roots 从会话日志重建。
- 工作区 chip 有附加目录时显示 `+N`（如 `FireShot +1`）。
- 再次打开「多选工作区…」会按会话真实 roots 回填勾选（已验证 FireShot + pj 同时勾选）。
- `/roots list|add|remove|clear` 语义不变；`/roots add` 的原始参数与结果都留在日志里。

### 3. 副会话（Ctrl+;）行为修正

- **总是新建空白会话**（同一工作区；无工作区时同 `cwd`），不再 fork、不把主会话内容带过来。
- 右栏「+」在已有副会话时直接再开一个副会话，不再弹 tab guide；没有副会话时保持原行为（guide）。
- 会话页头部「⧉ 副会话」按钮作为第二个入口。
- 旧的 `dsh:side-session` bundle 补丁保持移除状态（快捷键由插件注册）。

### 4. 插件作用域面板默认值

- `dsh-plugin-scope` 面板不再要求 `lib/scope.js` 才显示作用域：所有 profile 全局插件默认按工作区记录开关，移除了「只看支持作用域」过滤。
- 真正按工作区生效仍取决于插件是否读取 `<工作区>/.dsh/plugins.json`（trellis / gitnexus / codegraph 已实现）。
- `/pluginscope` 命令同时放宽为接受任意插件名（`/pluginscope @local/dsh-side-chat off` 等）；本机已同步，0.2.9 安装包内仍是旧的 trellis/gitnexus/codegraph 白名单，下一次构建带入。
