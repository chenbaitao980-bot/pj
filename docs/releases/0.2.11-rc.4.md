## 相对 0.2.11-rc.3 的改动

### 1. 让任务清单真正自动出现（`@local/dsh-todo-nudge`）

- 任务面板的数据来自会话 `todos` 投影，而投影只有模型调用 `todo_write` 后才有——所以「面板在哪」取决于模型有没有建清单。
- 新插件注册 system prompt 段 `todo:nudge`（order 8600），仅在当前步骤的工具集里存在 `todo_write` 时输出：
  - 多步任务（三步以上或多次工具调用）先用 `todo_write` 建清单；
  - 当前步骤 `in_progress`，完成立即 `completed` 并把下一步设为 `in_progress`；
  - 清单实时显示在输入框上方的「任务」面板里，状态必须真实；
  - 单步小事不建清单。
- 未装该插件时该段为空，提示词零变化。

## 面板位置

- 面板在**输入框正上方**（`conversation.input.dock`），有清单时默认展开，显示表头（`已完成 / 进行中 / 待处理` 计数）与逐行状态；点表头可收起。
- 没有清单的会话不显示面板（这是 rc.1 之前就有的行为，本次未改）。

## 验证

- 段逻辑单测：无 `todo_write` → 空串；有 → 完整提示。

- 打包流水线（`Build-FrozenSetup.ps1`）自动 ship 新插件、重跑界面补丁并校验。
