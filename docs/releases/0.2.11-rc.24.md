本版把 OpenViking 接入为 DSH 的长期记忆层，并修掉存石蛊「无变更仍反复重建全量同步 payload」的空转。OpenViking 的运行时、模型和数据都放在项目目录内，DSH 启动时由 bootstrap 插件自动拉起；复制项目到其他电脑并重装冻结包后，插件、配置和运行脚本可以直接复用。

## 1. OpenViking 记忆层

- 服务端：`openviking==0.5.4.1`，独立 venv：`runtime/openviking/venv`。
- 数据：`runtime/openviking/data`，不写入用户目录；`ovcli.conf` 只保存 `http://127.0.0.1:1933`。
- Embedding：本地 `bge-small-zh-v1.5-f16`，512 维，模型缓存 `runtime/openviking/models`，不依赖云端 embedding。
- 离线 VLM fallback：Qwen2.5-3B-Instruct Q4_K_M，`llama.cpp` CPU 推理，端口 `8081`，`n_ctx=10240`。
- 默认 VLM：DSH 当前 agent 模型。bootstrap 内置 OpenAI 兼容 bridge（`127.0.0.1:8082`），底层调用 `ctx.llm.stream`，自动跟随 `agentDefaultModel.currentSelection()`；调用失败时回退到 8081 的 3B。
- 官方 DSH 插件：`@openviking/dsh-memory-plugin@0.5.34`，负责 `agent/pre-step` 注入、会话捕获、turn end commit、recall 和 MCP 工具。
- 启动链：DSH host 加载 `@local/dsh-openviking-bootstrap` → 启动 VLM（若未运行）→ 启动 OpenViking Server → 等待 `/health` 和 `/ready` → 再启用 bridge。
- 当前实测：3B 抽取成功，写入 `viking://user/default/memories/preferences/user_id/沟通风格.md`；`ov find "YG 偏好 中文 简洁"` 命中，score 0.7298。

## 2. DSH 模型 bridge

- `plugins/dsh-openviking-bootstrap/index.js` 提供 `/v1/models` 与 `/v1/chat/completions`，支持 OpenAI SSE 流。
- 调用 DSH 模型时固定带 `sessionId`，满足 opencode 的 `x-opencode-session` 路由头要求；不带该头会返回 `400 MissingSessionID`。
- 真实调用已验证：`opencode-go / deepseek-v4.1-flash / reasoningEffort=max` 返回 `成功`，`finish.kind=stop`。
- bridge 失败时转发到 `runtime.openviking.bridge.fallback`，默认 3B；3B 只作为离线兜底，不抢默认路径。
