- 新增四档叠加色 `--dsh-alpha-1..4`（`color-mix` + `--dsw-alias-label-primary` 4%/8%/13%/20%），原主题的 `--dsw-alias-interactive-bg-hover` 只有一档；
- 补 `transition: background-color/color/box-shadow 120ms cubic-bezier(.32,.72,0,1)`，覆盖 `wtg9ga_iconButton`、`wtg9ga_panelRow`、`wtg9ga_newSession`、`wnFoaW_sessionRow`、`wnFoaW_projectRow`、`wnFoaW_searchResultRow`、`wnFoaW_iconButton`、`GAkraW_searchButton`、`GAkraW_clearButton` 等；

- 通过 `html [class*="..."]:hover` 提高特异性压过原单档规则，原规则保留（不删不改，纯增量）。

## 3. ② 切会话的「载入历史…」

实测（逐帧 zstd 解压 123 个会话日志）：中位会话数据侧 15ms、P90 97ms、最大 576ms。**慢的不是数据，是「loading 就整屏换文字」这个视觉行为**。

- `dsh-client-ui-chat` 的 `openState === "loading"` 分支不再渲染文案节点，改为挂 `aria-label` + `dsh-chat-skeleton` 骨架（4 条渐变块，1.4s 呼吸，`prefers-reduced-motion` 下关闭）；
- `dsh-client-ui-workspace` 的会话行 `onPointerEnter` 追加 `window.__dshPrefetchSession?.(node.id)`：hover ≥150ms 才 `open()`，仅对 `openState === 'cold'` 生效，`open()` 自身幂等，异常吞掉；
- 不改 `RemoteJournalStream`、不改 `HISTORY_PAGE_OPTIONS`（仍 500 条 / turn window 50 条 / 2 轮）。

## 6. ⑤ 工作态文案

`dsh-client-ui-chat` 的 `RunningStatus` 原来只有一条固定模板「深度求索中，用时 X」。现在：

- `dsh-cc-touch` 暴露 `window.__dshRunningLabel()`：读 `[data-tool][data-state="running"]` 最后一个工具卡，按类型给动词（正在编辑 / 正在运行命令 / 正在读取 / 正在检索 / 正在整理任务 / 正在调用 MCP / 正在分派子任务），edit/read/search 追加文件名；
- chat 侧 patch 优先用它，拼成 `正在编辑 foo.ts · 用时 12 秒`；拿不到时回退原「深度求索中」文案；
- 中文/英文跟随 UI 语言；时长部分沿用原 `formatRunDuration`。
