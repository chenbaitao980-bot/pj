## 1. Upgrade.ps1：保留本机安装的插件声明

- 现象：rc.12 升级后 `~/.dsh/profiles/desktop/package.json` 变成冻结版模板的内容，`dsh-computer-use-win` 的 `dependencies` 与 `dsh.profile.bundles` 条目消失；插件目录还在（空的），插件页显示「包不可用 / 包缺失」。
- 原因：第 3 步用 `robocopy /E` 把 `dsh-home` 模板合并到 `~/.dsh`，会覆盖 `profiles/desktop/package.json`；模板里没有用户后来安装的插件。
- 修复：复制前先读出本机 profile 的 `dependencies` 与 `dsh.profile.bundles`，合并完成后把模板中不存在的条目补回去（只补声明，不动版本/文件），再执行原有的插件依赖自检。清单以 UTF-8 无 BOM 写回。
- 标记 `# /*dsh:keep-user-plugins*/`；`verify-install.ps1` 新增检查 `upgrade: keeps user plugin declarations`（payload 自检 58/0）。
