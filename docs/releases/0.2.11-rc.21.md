## 2. 两个关键坑（写进插件 README 与 changelog 第 30 节）

1. **不能用 `node_repl.exe`**：它的 worker 是受限沙箱，`spawn` 一律 `EPERM`（连 `cmd /c echo hi` 都不行），
   而 helper 必须拉起 `codex app-server` 才能枚举窗口。改为普通 Node 进程直接 `import('@oai/sky')`。
2. **审批 shim 要两个条件同时满足**：`globalThis.nodeRepl.config` 非 null **且**根级有 `createElicitation`。
   缺任一条件，截图/取态全报 `Computer Use requires app approval but elicitations are unavailable`。
   DSH 的 MCP 客户端没有 elicitation 通道，由 `mcp/server.mjs` 自己兜（`approval: auto|deny`）。
