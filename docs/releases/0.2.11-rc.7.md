## 相对 0.2.11-rc.6 的改动（本轮评审 + 你的三条反馈）

### 1. 任务面板：下拉切换、逐 agent 停止、动态增删

- **只显示有清单的 agent**：主会话没有 `todos` 就不出现；没有清单的子 agent 不再占位。清单被清空后对应面板/选项随投影实时消失。
- **下拉框切换**：agent 多于一个时，表头出现「名称 + 完成数 + ▾」的切换按钮，点开是浮层列表（可滚动），不再用会溢出的横向 tab。
- **命名**：优先用子 agent 的 catalog `label`；没有 label 时显示「子智能体 N」，原始提示词放在 tooltip 里，不再满屏「你是本次…」。
- **停止**：
  - 每个正在运行的 agent 行上有停止按钮（主会话走 `session.cancel`，子 agent 走 `subagents.interruptByParent`）；
  - 浮层底部「停止整个会话」一次停掉主会话与所有在跑的子 agent；
  - 停止后 `in_progress` 项显示「已暂停」+ 静态点，不再转圈。
- 表格只保留一层 padding，表头与列表对齐；展开/收起、自动展开逻辑沿用。

### 2. `/purge revert` 真正保全部冻结补丁

- `FROZEN_PATCH_SCRIPTS` 补齐为 5 个：`patch-todo-panel`、`patch-slash-plugin-group`、`patch-task-board`、`patch-workspace-roots-chip`、`patch-no-workspace`。之前只重打 2 个，revert 后会出现「上游面板与任务面板叠加、chip +N 消失」。
- 新增 **CLI `dsh-purge --revert`** 路径的补打（`revertAllHosts` 内逐个宿主重打），原来只有 4 条界面路径。
- 安装根推导：优先 `desktop.inferDesktopInstallDir()`，回退 5 级 `..`；兼容 `app.asar.unpacked` 布局。
- 脚本运行：优先安装包自带 node；回退 `DSH_NODE`，只有当 `process.execPath` 是 node 时才用它。spawn 带 `ELECTRON_RUN_AS_NODE=1`、30 秒超时与 stderr 捕获，失败原因写进报告。
- 报告：命令 / 工具 / HTTP / 卸载 / CLI 都会列出「已重打」「未随包提供」「重打失败」。
- 卸载时重打放进 `finally`，`revertAll` 抛错也会补。

### 3. 打包与安装脚本

- `Build-FrozenSetup.ps1` 同步并顺序执行**全部 7 个界面补丁脚本**（含 no-workspace / multi-workspace-ui / sidebar-add-tab / roots-chip），并在打包前跑 `verify-install.ps1`，不通过即中止；同时把 `Build-FrozenSetup.ps1`、`ship-plugin.js`、7 个补丁脚本写进 payload，避免「包里的重建脚本是旧的」。
- `install.ps1` 的安装回执从 profile `bundles` 生成插件清单（不再写死）；安装/升级都会清掉旧包遗留的 `dsh-purge/.git`。
- `sync-live-plugins.js` 同样跳过 `.git`/`node_modules`。
- 多工作区多选：`/roots add` 失败会回传 `failedRoots`，弹窗提示哪些目录没挂上（不再假成功）。
