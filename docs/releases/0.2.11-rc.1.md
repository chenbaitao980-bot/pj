## 相对 0.2.10-rc.1 的改动

### 1. `/` 菜单新增「插件」分组

- 会话输入框里打 `/` 时，除「指令」「技能」外新增「插件」分组，列出当前 profile 真正加载且启用的插件（自动排除 `@deepseek-ai/*` 等 Harness 自身包）。
- 每行显示插件的中文标题与说明（来自包内 `locale/*.json`），选中后把 `使用插件 <包名> ` 插入草稿，用户接着写需求即可。
- 实现：新插件 `@local/dsh-plugin-slash` 注册一个 `/` 输入源（`inputTriggers.registerSource`）；库存来自 `remote.pluginInventory.list()`，`plugin-manager/changed` 时失效重取。
- 分组标题走 `slash.menu` 字典，由 `patch-slash-plugin-group.js` 在 zh/en 字典补 `"plugin": "插件" / "Plugins"`（其它语言的 `slash.menu` 字典没有该键，按 locale 回退链落到英文 `Plugins`）。

### 2. 会话内管理工作区（`/` 或 `+` 菜单）

- 之前只能在新建会话时多选工作区，会话开起来就改不了。本版新增命令 `工作区 /workspaces`（command contribution，`kind: "action"`），因为输入框左下角的 `+` 打开的正是指令菜单，所以两条入口都能到达。
- 弹窗「管理工作区」：显示主目录（只读）、附加目录列表；支持
  - **添加目录…**：调用系统目录选择器，再走 `Host /roots add <绝对路径>`；
  - **更换**：选新目录后先 `/roots remove` 再 `/roots add`；
  - **移除**：`/roots remove`。
- 所有改动都落在 `/roots` 命令上，因此会话投影 `multiWorkspaceRoots` 立即更新、模型下一轮请求就能看到；`+N` chip 同步变化。
- `dsh-multi-workspace` 升到 1.2.0。

### 3. 联网搜索优先走 websearch 插件

- 新插件 `@local/dsh-websearch-preference` 注册 system prompt 段 `websearch:preference`（order 8500）：
  - 当本轮的可用工具里同时出现 `web_search_meta`（`dsh-tool-websearch`）与内置 `web_search` 时，要求模型**先用 `web_search_meta`**，只有它返回空结果、报错或超时才回退 `web_search`；
  - 只有 `web_search_meta` 时给出单工具指引；
  - 没有装该插件时该段为空，提示词与之前完全一致。
- 不改工具、不隐藏内置搜索，因此兜底始终可用。

### 4. 会话任务清单实时展示

- 会话输入框上方的待办面板改为**默认展开**，并新增：
  - 任一条目变成「进行中」时自动重新展开（用户手动收起后也一样）；
  - 每行右侧标注「已完成 / 进行中 / 待处理」；
  - 已完成条目划线并降为次要色，进行中条目加粗提亮。
- 数据仍来自会话 `todos` 投影，随工具调用实时更新，无轮询。
- 实现：`patch-todo-panel.js` 修改 `dsh-client-ui-conversation` 的 `TodoPanel`。

## 已知限制

- 「插件」分组的说明文字跟随包内的 zh/en 文案；只提供英文的插件在中文界面下显示英文说明（属预期）。
- 工作区弹窗的「更换」= 移除旧目录 + 添加新目录，两步都会写入会话日志；中途失败会保留原目录并报错。
- `websearch:preference` 是提示词级约束，不是强制路由：模型仍可在明显需要内置搜索时自行选择。
