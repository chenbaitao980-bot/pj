## 相对 0.2.7-rc.1 的改动

### 1. 工作区下拉多选（`@local/dsh-multi-workspace` 1.1.0）

- 工作区下拉新增「多选工作区…」。勾选多个工作区后：
  - 第一个勾选的作为会话主目录（`workspaceId` / `cwd` 不变，侧栏分组正常）；
  - 其余目录通过 Host `/roots add <绝对路径>` 挂到同一会话，模型按绝对路径跨目录读写；
  - 客户端走 `ctx.remote.commands.execute()`，不产生用户可见消息。
- 新增 `UiWorkspaceService.openWorkspaceWithRoots()`（`patch-multi-workspace-ui.js`）：建/复用空白会话 → 逐个附加 roots → 展示会话。
- **roots 持久化**：`~/.dsh/multi-workspace/roots.json`，Host 重启后仍生效（旧版只存在内存）。
- 插件名单里同步更新了中文/英文描述。

### 2. `Ctrl+;` 右侧副会话（`@local/dsh-side-chat` 1.0.0）

- 参考 Claude Code 桌面版的 side chat：副会话以**右侧面板 tab** 的形式出现，自己的输入框、自己的 agent loop，主会话保持可见可继续。
- 新资源协议 `dsh-resource://sidechat/session/<id>` + 右栏 tab kind `sidechat`；tab 内用 `SessionProvider` 渲染完整的 `conversation.session`。多次按 Ctrl+; 可开多个副会话 tab。
- **永远生效**：
  - 当前会话有已完成轮次 → fork（带历史）；
  - 当前会话是空白（或 fork 被拒）→ 在同一工作区新建空白会话；无工作区则沿用当前 `cwd`；
  - 完全没有会话 → 先开一个普通会话。
- 会话页头部同时提供一个「副会话」按钮，便于发现。
- 旧的 bundle 补丁 `dsh:side-session` 已移除（否则同一快捷键 id 注册两次），由 `unpatch-side-session.js` 清理。
